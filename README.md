# Huddle Landing Page with Alternating Feature Blocks

![Desktop preview](./design/desktop-preview.jpg)

Solución al challenge de [Frontend Mentor](https://www.frontendmentor.io/challenges/huddle-landing-page-with-alternating-feature-blocks-5ca5f2961e82137ec91a50f2).

## Overview

Landing page responsive para un producto ficticio llamado **Huddle**, una plataforma para construir comunidades. El diseño alterna bloques de contenido con ilustraciones, adaptándose de mobile a desktop.

## Built With

- HTML5 semántico
- CSS3 (Flexbox, Custom Properties, Mobile-first)
- Fuentes locales: Poppins (headings) + Open Sans (body)
- Sin frameworks ni JavaScript

## Features

- Diseño mobile-first con un breakpoint en 768px
- Bloques de contenido alternados (imagen ↔ texto)
- Hover states en botones y enlaces
- Gradiente CSS para efecto de superposición en sección CTA
